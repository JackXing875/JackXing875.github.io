# Website fonts

Self-hosted WOFF2 files keep typography independent of third-party font requests.

- Lora variable (Latin, normal and italic): `@fontsource-variable/lora` 5.3.0.
- Poppins (Latin, normal, weights 400/500/600/700): `@fontsource/poppins` 5.3.0.

Both families use the SIL Open Font License; see `Lora-OFL.txt` and `Poppins-OFL.txt`.
Chinese text falls back to local Songti/SimSun or PingFang/Microsoft YaHei fonts.
